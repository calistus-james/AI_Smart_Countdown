AI Smart Countdown – Project Details



Project Information



Project Name: AI Smart Countdown



Project Type: Windows Desktop Application



Project Description: Intelligent To-Do \& Deadline Reminder Desktop Application



Programming Language: Java 21



User Interface: JavaFX



Database: SQLite



Build Tool: Gradle



AI Integration: Google Gemini API



Project Objectives



1\. Provide efficient task and deadline management.

2\. Display live countdowns for upcoming deadlines.

3\. Identify overdue tasks automatically.

4\. Store task information persistently using SQLite.

5\. Use Gemini AI to assist with task organization and planning.



Implemented Modules



1\. Task Management



\- Add tasks

\- Edit tasks

\- Delete tasks

\- Complete and reopen tasks



2\. Countdown Management



\- Live countdown

\- Overdue calculation

\- Automatic countdown refresh



3\. Database Management



\- SQLite database initialization

\- Task insertion, retrieval, updating and deletion

\- Persistent storage



4\. AI Assistant



\- AI Task Suggestions

\- AI Priority Analysis

\- AI Task Breakdown



5\. Error Handling



\- Gemini API error handling

\- Network error handling

\- User-friendly error messages



Build and Execution



Build:



.\\gradlew.bat clean build



Run:



.\\gradlew.bat run



Project Completion



The core application functionality and three Gemini AI features have been implemented and tested successfully.
